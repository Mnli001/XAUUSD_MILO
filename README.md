# XAU Analytics

Алтны (XAUUSD) трейдерүүдэд зориулсан шинжилгээний веб систем: өнөөдрийн чиглэл, давамгай тал, цаг тутмын өсөх/унах магадлал, мэдээний календарь, арилжааны журнал, гүйцэтгэлийн анализ, админ самбар.

> Систем түүхэн статистик дээр суурилсан тооцоо гаргана. Санхүүгийн зөвлөгөө биш.

## Технологи

Next.js (App Router) · TypeScript · Tailwind · PostgreSQL · Drizzle ORM · Auth.js · Lightweight Charts · Vitest

## Локал дээр ажиллуулах

1. PostgreSQL-д `xau` (хөгжүүлэлт), `xau_test` (тест) гэсэн хоёр бааз үүсгэнэ.
2. `.env.example`-г `.env` болгож хуулаад утгуудыг бөглөнө.
3. Суулгах, бааз бэлдэх:

```bash
npm install
npm run db:migrate          # хүснэгтүүд
npm run seed                # ADMIN_EMAIL / ADMIN_PASSWORD-оор админ үүсгэнэ
npm run backfill            # алтны түүхэн лаа (~10 минут, үнэгүй багцын хязгаараас болж удаан)
npm run dev
```

4. Мэдээний календарь татах: `curl -X POST -H "Authorization: Bearer $CRON_SECRET" http://localhost:3000/api/cron/calendar`
5. Тест: `DATABASE_URL=postgresql://postgres:postgres@localhost:5432/xau_test npm run db:migrate` (нэг удаа), дараа нь `npm test`

## Орчны хувьсагчид

| Нэр | Тайлбар |
|---|---|
| `DATABASE_URL` | PostgreSQL холболт |
| `AUTH_SECRET` | `openssl rand -base64 32` |
| `TWELVEDATA_API_KEY` | twelvedata.com — үнийн дата |
| `FRED_API_KEY` | fred.stlouisfed.org — мэдээний огноо |
| `CRON_SECRET` | cron дуудлагыг хамгаалах нууц үг |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | `npm run seed`-д хэрэглэгдэнэ |

## Эхний удаа шалгах зүйлс

- `npm run check-fred` — FRED-ийн release id бүр зөв мэдээг зааж байгаа эсэхийг хэвлэнэ. Буруу байвал `src/lib/data/calendarProvider.ts` дотор засна.
- FOMC-ийн огноо, таамаг/бодит тоог **Админ → Мэдээ** хэсгээс гараар оруулна.

## Railway дээр байршуулах

1. Шинэ project → GitHub repo-г холбоно, PostgreSQL нэмнэ.
2. Web service-д дээрх хувьсагчдыг оруулна (`DATABASE_URL`-г Postgres-оос reference хийнэ). `railway.json` нь build, migration, start-ыг тохируулсан.
3. Deploy болсны дараа нэг удаа: `railway run npm run seed`, `railway run npm run backfill`.
4. Web service-д `ENABLE_SCHEDULER=1` хувьсагч нэмнэ. Ингэхэд сервер өөрөө 5 минут тутам 15 минутын лаа, цаг тутам 1ц / 4ц / өдрийн лаа, өдөрт нэг удаа мэдээний календарийг татна. Тусдаа cron service хэрэггүй. (`/api/cron/*` хаягууд гараар дуудахад хэвээр ажиллана.)

Үнэгүй багцын хэрэглээ: өдөрт ойролцоогоор 360 хүсэлт (хязгаар 800).

## Тооцоолол товчхон

- **Давамгай тал:** timeframe бүрт −100…+100 оноо = тренд (EMA20/50/200) + моментум (RSI, MACD) + бүтэц (оргил/ёроол). Жин: өдөр 35%, 4ц 30%, 1ц 20%, 15м 15%. ≥ +20 бол "ӨСӨХ хандлага", ≤ −20 бол "УНАХ хандлага".
- **Цагийн магадлал:** сүүлийн 183 хоногийн 1 цагийн лаа, УБ цагаар. Түүвэр 30-аас цөөн бол хувь гаргахгүй.
- **Мэдээний хариу үйлдэл:** сүүлийн 12 сарын ижил төрлийн мэдээний дараах 15/30/60 минутын хөдөлгөөн. 6-аас цөөн бол гаргахгүй.
- **Журнал:** 1 лот = 100 унц. P&L = (гарсан − орсон) × чиглэл × лот × 100.

## Зарахаас өмнө шийдэх зүйлс

- **Үнийн датаны эрх:** үнэгүй багц хоцролттой бөгөөд арилжааны зорилгоор хэрэглэхэд бизнес багц шаардана. Эх сурвалжийг солихдоо `src/lib/data/priceProvider.ts`-ийн `PriceProvider`-г хэрэгжүүлсэн шинэ адаптер бичихэд хангалттай.
- **Төлбөр:** одоогоор админ гараар эрх нээнэ (Админ → Хэрэглэгчид). QPay-г дараа нэмнэ.

## Бот: backtest ба цаасан арилжаа

Зөвхөн админд харагдана (**Админ → Бот**). Жинхэнэ болон demo захиалга хаашаа ч илгээгдэхгүй.

| Команд | Үүрэг |
|---|---|
| `npm run backfill` | 3 орчим жилийн лаа татна (`npm run backfill -- 15min` гэж хэсэгчлэн татаж болно) |
| `npm run calendar -- 1100` | 3 жилийн мэдээний огноо |
| `npm run backtest` | Анхны дүрмийн backtest |
| `npm run variants` | Анхны дүрмийн 13 хувилбар, сонгох / баталгаажуулах хуваалттай |
| `npm run ideas` | Гурван өөр санаа (хүрээний breakout, трендийн уналт, мэдээ) |

Одоогийн байдал (2026-11-20): backtest-ээр 19 дүрмийн аль нь ч урьдчилан тогтоосон шалгуурыг даваагүй. “Азийн хүрээний breakout + өдрийн тренд” дүрмийг таамаглал болгон **цаасан арилжаагаар** (`/admin/bot/paper`) урагшаа шалгаж байна: 40 арилжаа, дундаж R ≥ 0.1, profit factor ≥ 1.2. Цаасан арилжаа нь хадгалагдсан лаанаас дахин тооцогддог тул cron тасралтгүй ажиллаж байх ёстой.

## Бот: MT5 дээр автомат арилжаа

Хэрэглэгч бүр өөрийн **Бот** хуудаснаас (`/bot`) өөрийн MT5 доторх роботыг удирдана: токен, тохиргоо, Start/Stop, арилжааны түүх хүн бүрд тусдаа. Холбох заавар болон `XauBot.ex5` файлын таталт тэр хуудсан дээр байна. Арилжааг робот (`mt5/XauBot.mq5`) брокерын бодит цагийн үнээр өөрөө хийдэг; вэб нь тохиргоо, Start/Stop, хяналт.

> Scalper арга шалгагдаагүй: ашигтай гэдэг нь нотлогдоогүй. Эхлээд demo данс дээр ажиллуул.
> `mt5/XauBot.ex5` нь `XauBot.mq5`-аас MetaEditor-оор хөрвүүлсэн файл (0 алдаа, 0 анхааруулга). `.mq5`-ийг өөрчилбөл дахин хөрвүүлж `.ex5`-ийг шинэчилнэ.

### Суулгах

1. MT5 → **File → Open Data Folder** → `MQL5/Experts/` дотор `XauBot.mq5`-ийг хуулна.
2. MetaEditor-т нээж **Compile (F7)**. Алдаа гарвал бичвэрийг нь хадгалж ав.
3. MT5 → **Tools → Options → Expert Advisors** → *Allow WebRequest for listed URL* → сайтын хаягийг нэмнэ (жишээ: `https://xau-analytics-production.up.railway.app`).
4. Вэб дээр **Админ → Бот → Токен үүсгэх**. Токен нэг л удаа харагдана.
5. XAUUSD (эсвэл брокерын нэрээр `XAUUSDm` гэх мэт) чарт нээж, роботыг чирж тавина. Inputs: `ServerUrl` (вэб дээр харагдана), `BotToken`. Жинхэнэ данс бол `AllowRealAccount = true`.
6. MT5-ийн **Algo Trading** товчийг асаана. Чартын зүүн дээд буланд “вэб: холбогдсон” гэж гарна.

### Ажиллуулах

- Вэб дээр лот, зэрэг нээх арилжааны тоо, stop/target, зогсох нөхцөлөө тохируулаад **Start bot**.
- Робот M1 EMA9/EMA21, M5 EMA50 тренд, RSI(7)-ээр чиглэлээ тодорхойлж, арилжаа бүрийг stop loss, take profit-той нээнэ.
- Хэр удаан ажиллахаа робот өөрөө тооцно: эхний арилжаагаа нээхдээ target хүртэлх зай, одоогийн хэлбэлзлээс (target ATR × -ийн квадрат × 90 секунд, 30 сек – 15 мин) хугацаагаа тогтооно. Тэр хугацаа дуусах, чиглэл эргэх, эсвэл 30 минутад дохио гарахгүй бол бүх арилжаагаа хаагаад зогсоно.
- Мөн **Stop** товч болон сонголтоор тавьсан ашиг / алдагдлын хэмжээнд хүрэхэд зогсоно.
- Вэбтэй холбоо 30 секундээс удаан тасарвал робот шинэ арилжаа нээхгүй (нээлттэй нь stop/target-аараа хаагдана).
- MT5 унтарвал робот зогсоно. Тасралтгүй ажиллуулахад Windows VPS хэрэгтэй.

### Жинхэнэ данс

Жинхэнэ данс дээр ажиллуулахад хоёр газар зөвшөөрөл хэрэгтэй: вэб дээрх “Жинхэнэ данс дээр арилжаа хийхийг зөвшөөрөх” болон роботын `AllowRealAccount`. Аль нэг нь унтраалттай бол арилжаа хийгдэхгүй.
