# XAU Analytics

Алтны (XAUUSD) трейдерүүдэд зориулсан веб систем: нэг тогтсон, шалгагдсан дүрмээр гарах дохио (Telegram бот, MT5 робот, live чарт), өдрийн чиглэл, цаг тутмын өсөх/унах магадлал, мэдээний календарь, өглөөний тойм, арилжааны журнал, demo данс, гүйцэтгэлийн анализ, админ самбар. Системийн бүрэн тодорхойлолт: [docs/SYSTEM_SPEC.md](docs/SYSTEM_SPEC.md).

> Систем түүхэн статистик дээр суурилсан тооцоо гаргана. Санхүүгийн зөвлөгөө биш.

## Технологи

Next.js (App Router) · TypeScript · Tailwind · PostgreSQL · Drizzle ORM · Auth.js · Lightweight Charts · Vitest

## Локал дээр ажиллуулах

1. PostgreSQL-д `xau` (хөгжүүлэлт), `xau_test` (тест) гэсэн хоёр бааз үүсгэнэ.
2. `.env.example`-г `.env` болгож хуулаад утгуудыг бөглөнө.
3. Суулгах, бааз бэлдэх:

```bash
npm install
npm run db:migrate          # хүснэгтүүд
npm run seed                # ADMIN_EMAIL / ADMIN_PASSWORD-оор админ үүсгэнэ
npm run backfill            # алтны түүхэн лаа (~10 минут, үнэгүй багцын хязгаараас болж удаан)
npm run dev
```

4. Мэдээний календарь татах: `curl -X POST -H "Authorization: Bearer $CRON_SECRET" http://localhost:3000/api/cron/calendar`
5. Тест: `DATABASE_URL=postgresql://postgres:postgres@localhost:5432/xau_test npm run db:migrate` (нэг удаа), дараа нь `npm test`

## Эхний удаа шалгах зүйлс

- `npm run check-fred` — FRED-ийн release id бүр зөв мэдээг зааж байгаа эсэхийг хэвлэнэ. Буруу байвал `src/lib/data/calendarProvider.ts` дотор засна.
- FOMC-ийн огноо, таамаг/бодит тоог **Админ → Мэдээ** хэсгээс гараар оруулна.

## Railway дээр байршуулах

1. Шинэ project → GitHub repo-г холбоно, PostgreSQL нэмнэ.
2. Web service-д дээрх хувьсагчдыг оруулна (`DATABASE_URL`-г Postgres-оос reference хийнэ). `railway.json` нь build, migration, start-ыг тохируулсан.
3. Deploy болсны дараа нэг удаа: `railway run npm run seed`, `railway run npm run backfill`.
4. Web service-д `ENABLE_SCHEDULER=1` хувьсагч нэмнэ. Ингэхэд сервер өөрөө 5 минут тутам 15 минутын лаа, цаг тутам 1ц / 4ц / өдрийн лаа, өдөрт нэг удаа мэдээний календарийг татна. Тусдаа cron service хэрэггүй. (`/api/cron/*` хаягууд гараар дуудахад хэвээр ажиллана.)

Үнэгүй багцын хэрэглээ: өдөрт ойролцоогоор 360 хүсэлт (хязгаар 800).

## Тооцоолол товчхон

- **Давамгай тал:** timeframe бүрт −100…+100 оноо = тренд (EMA20/50/200) + моментум (RSI, MACD) + бүтэц (оргил/ёроол). Жин: өдөр 35%, 4ц 30%, 1ц 20%, 15м 15%. ≥ +20 бол "ӨСӨХ хандлага", ≤ −20 бол "УНАХ хандлага".
- **Цагийн магадлал:** сүүлийн 183 хоногийн 1 цагийн лаа, УБ цагаар. Түүвэр 30-аас цөөн бол хувь гаргахгүй.
- **Мэдээний хариу үйлдэл:** сүүлийн 12 сарын ижил төрлийн мэдээний дараах 15/30/60 минутын хөдөлгөөн. 6-аас цөөн бол гаргахгүй.
- **Журнал:** MT5-ын арилжаа роботоос (багцтай), эсвэл хэрэглэгч гараар бичнэ (бүх бүртгэлтэй хэрэглэгч, багцгүй ч). Гараар бичсэн арилжааны P&L = (гарсан − орсон) × чиглэл × лот × 100 унц; swap, шимтгэл ороогүй. Хоёулаа нэг анализад орно (`journal_trades`, `source` = `mt5` | `web`).

## Зарахаас өмнө шийдэх зүйлс

- **Үнийн датаны эрх:** үнэгүй багц хоцролттой бөгөөд арилжааны зорилгоор хэрэглэхэд бизнес багц шаардана. Эх сурвалжийг солихдоо `src/lib/data/priceProvider.ts`-ийн `PriceProvider`-г хэрэгжүүлсэн шинэ адаптер бичихэд хангалттай.
- **Төлбөр:** Wire (wire.mn)-ийн hosted checkout: хэрэглэгч QPay / банкны апп (мөн карт, Toki)-аар төгрөгөөр төлж, Wire баталгаажуулмагц эрх автоматаар нээгдэнэ (`src/lib/payments.ts`, `src/lib/wire.ts`). Багц: Plus 1 сар, Pro 6 сар, Max 1 жил; боломж нь ижил. Админ эрхийг гараар ч нээж болно (Админ → Хэрэглэгчид).

## Хэл, өнгөний горим, цагийн бүс

Хэрэглэгч бүр **Тохиргоо** (`/settings`) хуудаснаас хэл (20 хэл: монгол, англи нь кодонд бичигдсэн, бусад 18 нь англи бичвэрийн орчуулга `src/locales/*.json`, орчуулгагүй мөр англиар гарна), өнгөний горим (бараан / цайвар / төхөөрөмжийг дагах), цагийн бүсээ сонгоно. Сонголт `users` хүснэгтэд хадгалагдаж, нэвтрээгүй хуудсуудад зориулж хөтчид (`xau_locale`, `xau_theme`, `xau_tz` cookie) мөн үлдэнэ. Тэнд Telegram дохионы сонголт, журнал татах (CSV), бүртгэл устгах мөн байна.

- **Бичвэр:** хоёр хэлийг хэрэглэж буй газарт нь зэрэгцүүлж бичнэ: `t("Тохиргоо", "Settings")` (`src/lib/i18n.ts`). Сервер талд `getT()` / `getViewer()` (`src/lib/prefs.server.ts`), клиент талд `useT()` / `useViewer()` (`src/components/PrefsProvider.tsx`).
- **Шалгалт:** `tests/i18n-coverage.test.ts` эх кодыг уншиж, англи хувилбаргүй монгол бичвэр байвал унагана. Хадгалагдсан түлхүүр, серверийн лог зэргийг `// i18n-ok` гэж тэмдэглэнэ.
- **Цаг:** `Viewer` (`src/lib/viewer.ts`) нь `v.time(d)`, `v.dateTime(d)`, `v.zone`, мөн дүрмийн тогтмол УБ цагийг үзэгчийн цаг руу хөрвүүлэх `v.ub("15:00")`-тай. Статистикийн цагийн хуваалт УБ цагаар хэвээр, зөвхөн харуулахдаа хөрвүүлнэ. Админ хуудсууд УБ цагаар.
- **Өнгө:** `<html data-theme>`; цайвар палитр `src/app/globals.css` дотор өнгөний хувьсагчдыг дарж тодорхойлно.
- **Робот:** вэб sync хариундаа `lang` илгээж, робот v2.40 чартын бичвэрээ тэр хэлээр гаргана (Inputs дээрх `Language`-ээр тогтмол болгож болно).

## Систем: гурван setup, дохио, робот

Бүрэн тодорхойлолт [docs/SYSTEM_SPEC.md](docs/SYSTEM_SPEC.md)-д. Товчоор:

- **Гурван setup** (`src/lib/setup/sessionRules.ts`): Азийн хүрээ 00:00–07:00 UTC (target 3R), Нью-Йоркийн нээлт 12:30–13:30 ба Нью-Йоркийн 2 дахь цаг 13:30–14:30 UTC (target 2R, өдрийн trend оноо |≥ 35|). 15 минутын лаа хүрээний гадна хаагдаж, өдөр ба 4 цагийн trend нэг чиглэлд байвал л тоологдоно; өндөр нөлөөтэй мэдээний −30…+60 минутад орохгүй. Stop нь хүрээний дунд.
- **Хэмжээ:** балансын % (анхдагч 1%) эсвэл тогтмол лот. `sizeFactor`: хоёр trend ≥ 65 бол ×1.25, аль нэг нь < 35 бол ×0.75. Нэг чиглэлд setup-ийн позиц нээлттэй бол ×0.5. Нэг дор 3 позиц хүртэл. Робот лотыг дээш нь тоймлодоггүй: хамгийн бага лот ч сонгосон эрсдэлээс 1.2 дахинаас их бол алгасна (`SMALL_ACCOUNT_X`, `src/lib/lot.ts`).
- **Дохио (Telegram бот):** 15 минутын лаа бүрийн дараа (:01, :16, :31, :46) шалгаж, шинэ setup-ыг ~2 минутад зураг, орох/stop/target-тай илгээнэ; хаагдахад үр дүнг. Командууд: `/setup`, `/history`, `/news`, `/status`, `/stop`, `/resume`, `/reset`. Дохио зөвхөн багцтай хэрэглэгчид.
- **Өглөөний тойм:** арилжааны өдөр 08:00 УБ цагаар Telegram-аар: үнэ, хоёр trend оноо, өнөөдрийн 3 setup, чухал мэдээ (`src/lib/brief.ts`). Тохиргооноос унтраана.
- **MT5 робот (XauBot):** секунд тутам `/api/bot/sync`-тэй холбогдож, Telegram дохиотой яг ижил арилжаа хийнэ. Робот хуудаснаас **нэг товчоор суулгах** `XauBot-Setup.bat` (MT5-д роботыг хуулж, шинэ token, хаягийг бичнэ; шинэ token хуучныг хүчингүй болгоно) эсвэл гараар 3 алхмаар холбоно. Хамгаалалт: өдрийн 5% алдагдал, оргилоос 15% уналт, netting данс, нээлттэй эрсдэл 3× хэтрэх үед зогсоно. Анхдагчаар зөвхөн demo; жинхэнэ дансанд вэб дээрх зөвшөөрөл ба `AllowRealAccount = true` хоёул хэрэгтэй.
- **Журнал:** роботын илгээсэн MT5 арилжаа + гараар бичсэн арилжаа (засах, устгах боломжтой).
- **Demo trade:** live үнээр demo данс (`/demo`).
- **Markets хуудас** хасагдсан (`drizzle/0027_drop_markets.sql`).

## Шууд үнэ, олон стратегийн дүгнэлт, Telegram-ыг имэйлээр холбох

- **Шууд үнэ (MT5-аас).** Админ хэрэглэгчийн робот 1–2 секунд тутам сайттай холбогдохдоо илгээдэг bid/ask нь сайтын шууд үнэ болно (`live_ticks` хүснэгт, `GET /api/live`). Өнөөдөр, Чарт, Setup хуудсууд 2 секунд тутам шинэчлэгдэж, бүрдэж буй лаа үнийг дагана. Бусад хэрэглэгч MT5 холбох шаардлагагүй. Админы MT5 15 секундээс удаан чимээгүй болбол сайт өөрөө Twelve Data-ийн лааны үнэ рүү шилжиж, “Шууд биш” гэж бичнэ. Роботыг дахин хөрвүүлэх шаардлагагүй. Тасралтгүй шууд байлгахын тулд админы MT5-ыг VPS дээр ажиллуулна.
- **Аргуудын санал (дэмжлэг).** Setup хуудсанд (товчоор, хураасан байдлаар Өнөөдөр хуудсанд) түгээмэл 16 арга (EMA эгнээ, Golden cross, Ichimoku, MACD, RSI, Bollinger, Stochastic, Donchian, Азийн хүрээ, BOS/CHoCH, FVG, liquidity sweep, pivot, Fibonacci, өчигдрийн оргил/ёроол) одоогийн захыг хэрхэн уншиж байгааг шалтгаан, тоотой нь харуулна (`src/lib/analysis/reasoning.ts`). Эдгээр нь чартын уншилт; шалгагдсан дүрэм биш, дохио болон робот үүнийг ашигладаггүй. Өдрийн чиглэлээс зөрж болно.
- **Telegram бот.** Хэрэглэгч Telegram ботод бүртгэлтэй имэйлээ бичнэ, сайт дээр “Тийм, минийх” гэж дарж баталгаажуулна. Зөвхөн имэйл мэдсэнээр хэн нэгний дохиог авах боломжгүй. “Telegram холбох” товч дарсны дараа Тохиргоо хуудас холболтыг 3 минут хүртэл өөрөө шалгана; бусад хуудсанд Telegram нэг мөрийн чип болж харагдана. `TELEGRAM_BOT_TOKEN`, `PUBLIC_URL` тохируулсан бол сервер асахдаа webhook-оо өөрөө бүртгэнэ.
- **Загвар.** Нэвтэрсний дараах хэсэг liquid glass: тунгалаг самбар, гэрэлтсэн ирмэг, хөвөгч цэс. Урт тоо хайрцагтаа таслагдахгүй, жижгэрч багтана.

## 24 цагийн шууд үнэ: өөрийн Windows сервер (AWS)

Сайтын үнэ, график, 16 аргын дүгнэлт эзний MT5-аас ирэх үнээр шууд (2 секунд тутам) шинэчлэгддэг. MT5 унтарвал 5 минутын хоцролттой горим руу буцна. Тасралтгүй шууд байлгахын тулд MT5-ийг 24 цаг асаалттай Windows сервер дээр ажиллуулна:

1. Сервер дээрээ (Windows, Remote Desktop-оор орно) брокерынхоо **MetaTrader 5**-ыг суулгаж, дансаараа нэвтэрнэ. Үнэ л дамжуулах бол demo данс хангалттай.
2. Сайтад **админ** бүртгэлээрээ нэвтэрч **Бот** хуудаснаас `XauBot.ex5`-ийг татаж, MT5 → File → Open Data Folder → `MQL5/Experts/` дотор хуулна.
3. MT5 → Tools → Options → Expert Advisors → *Allow WebRequest for listed URL* → сайтын хаягаа нэмнэ.
4. Робот хуудаснаас **Токен үүсгэх** → **Тохиргооны файл татах (XauBot.set)**. XAUUSD чарт нээж роботыг чирээд Inputs → Load → тэр файлыг сонгоно.
5. **Algo Trading** товчийг асаана. Чартын буланд «вэб: холбогдсон» гэж гарч, сайт дээр үнийн хажууд **LIVE · MT5** тэмдэг асна.

Үнэ дамжуулахад роботыг **Start хийх шаардлагагүй**: зогссон төлөвтэй ч секунд тутам үнээ илгээнэ, арилжаа нээхгүй. Олон робот холбогдсон үед админы роботын үнийг сонгоно. Серверийн MT5 хаагдах, Windows шинэчлэгдэж унтрах үед дамжуулалт зогсоно: MT5-ийг Windows асахад автоматаар нээгдэхээр (Startup хавтас) тохируулна.
