# Amazon сервер дээр XauBot суулгах заавар

Зорилго: сервер дээрх MetaTrader 5-аас алтны үнийг сайт руу 24 цаг шууд дамжуулах.
Сайт: https://web-production-4f0081ec.up.railway.app

## Хэрэгтэй зүйлс

- Windows-той Amazon сервер (Remote Desktop-оор ордог)
- `XauBot.ex5` файл (энэ зааврын хамт илгээсэн)
- Брокерын MT5 данс (үнэ дамжуулахад demo данс хангалттай)
- Сайтын админ бүртгэл

## 1. MT5 суулгах

1. Сервер рүүгээ Remote Desktop-оор орно.
2. Брокерынхоо сайтаас MetaTrader 5-ыг татаж суулгана.
3. MT5-ыг нээж дансаараа нэвтэрнэ.

## 2. Роботын файлыг хуулах

1. `XauBot.ex5` файлыг сервер рүү хуулна (Remote Desktop цонх руу copy/paste хийж болно).
2. MT5 дээр **File → Open Data Folder** дарна.
3. Нээгдсэн хавтсаас `MQL5` → `Experts` рүү орж `XauBot.ex5`-ийг тэнд тавина.
4. MT5-ийн зүүн талын **Navigator** цонхонд **Expert Advisors** дээр баруун товч → **Refresh**. Жагсаалтад XauBot гарч ирнэ.

## 3. Сайттай холбогдохыг зөвшөөрөх

1. MT5 дээр **Tools → Options → Expert Advisors** таб.
2. **Allow WebRequest for listed URL**-ийг чагтална.
3. Доорх хаягийг жагсаалтад нэмээд OK дарна:

```
https://web-production-4f0081ec.up.railway.app
```

## 4. Токен ба тохиргооны файл авах

1. Сервер дээрх хөтчөөр сайтад админ бүртгэлээрээ нэвтэрнэ.
2. **Бот** хуудас руу орно.
3. «MT5 роботыг холбох» хэсэгт **Токен үүсгэх** товчийг дарна.
4. Гарч ирсэн **Тохиргооны файл татах (XauBot.set)** товчийг дарна. Файл Downloads хавтсанд татагдана.

Токен ганц удаа харагдана. Файлыг хэнд ч бүү өг.

## 5. Роботыг чарт дээр тавих

1. MT5 дээр **Market Watch** (Ctrl+M) → XAUUSD дээр баруун товч → **Chart Window**. Брокер тань өөр нэртэй бол (XAUUSDm, GOLD гэх мэт) тэрийг нээнэ.
2. Navigator-оос **XauBot**-ыг чарт руу чирнэ.
3. Гарсан цонхны **Inputs** таб → **Load** → татсан `XauBot.set` файлыг сонгоно. ServerUrl болон BotToken өөрөө бөглөгдөнө.
4. **Common** таб дээр **Allow Algo Trading**-ийг чагталж OK дарна.

## 6. Асаах

1. MT5-ийн дээд самбарын **Algo Trading** товчийг дарж ногоон болгоно.
2. Чартын зүүн дээд буланд «вэб: холбогдсон» гэж гарна.
3. Сайтын Өнөөдөр хуудсанд үнийн хажууд **LIVE · MT5** тэмдэг асна.

Үнэ дамжуулахад сайт дээр **Start bot дарах шаардлагагүй**. Робот зогссон төлөвтэй ч үнээ секунд тутам илгээж, арилжаа нээхгүй.

## 7. Сервер унтарсан ч өөрөө асдаг болгох

1. Windows + R → `shell:startup` гэж бичээд Enter.
2. Нээгдсэн хавтсанд MT5-ийн shortcut-ыг хуулна.
3. Windows-д автоматаар нэвтэрдэг (auto logon) тохиргоо хийсэн бол сервер дахин асахад MT5 өөрөө нээгдэж, робот үргэлжлүүлнэ.

## Асуудал гарвал

| Чартын буланд гарах бичвэр | Шалтгаан | Шийдэл |
|---|---|---|
| BotToken оруулаагүй | Тохиргооны файл ачаалаагүй | 5-р алхмын Load-ыг дахин хийнэ |
| WebRequest алдаа / холбогдоогүй | Хаяг зөвшөөрөгдөөгүй | 3-р алхмыг шалгана |
| unauthorized / токен буруу | Шинэ токен үүсгэсэн, хуучин нь хүчингүй | Шинэ `XauBot.set` татаж дахин ачаална |
| Сайт дээр LIVE гарахгүй | Algo Trading унтраалттай, эсвэл зах хаалттай (амралтын өдөр) | Товч ногоон эсэхийг шалгана |

Нэг дансанд нэг л токен хүчинтэй. Шинэ токен үүсгэвэл хуучин роботод шинэ файлыг дахин ачаална.
